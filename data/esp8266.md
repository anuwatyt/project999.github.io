# ESP8266 NodeMCU Development Board 

## Overview

NodeMCU คือบอร์ดพัฒนาโปรแกรมแบบ Open-source ที่ใช้ชิป **ESP8266EX** ของ Espressif Systems เหมาะสำหรับงาน IoT เนื่องจากมี Wi-Fi ในตัวและราคาถูก

---

## Specifications

| Parameter           | Value                                 |
|---------------------|---------------------------------------|
| MCU                 | Espressif ESP8266EX                   |
| CPU Architecture    | Tensilica L106 32-bit RISC            |
| CPU Speed           | 80 MHz (สามารถ overclock เป็น 160 MHz) |
| Wi-Fi Standard      | IEEE 802.11 b/g/n 2.4 GHz            |
| Wi-Fi Modes         | Station, Access Point, Station+AP     |
| Operating Voltage   | 3.3 V (GPIO ทนได้สูงสุด 3.6 V)        |
| Input Voltage (USB) | 5 V (ผ่าน USB Type-Micro B)           |
| Flash Memory        | 4 MB (บอร์ด NodeMCU ทั่วไป)            |
| SRAM                | 64 KB instruction RAM + 96 KB data RAM|
| GPIO จำนวน          | 17 pins (ใช้งานได้จริง 11 pins)        |
| ADC                 | 1 ช่อง (A0) — 10-bit, 0–3.3 V (ภายนอก 0–3.3 V, ผ่าน voltage divider 0–1 V) |
| PWM                 | ทุก GPIO (Software PWM)               |
| UART                | 2 ช่อง (UART0 = TX/RX, UART1 = TX เท่านั้น) |

| I2C                 | Software I2C (ใช้ได้ทุก GPIO)         |
| USB-to-Serial       | CH340G หรือ CP2102 (ขึ้นอยู่กับ batch)|
| Dimensions          | 49 × 26 mm (NodeMCU v2/v3)           |

## NodeMCU Pin Mapping (Complete)

| NodeMCU Pin | GPIO    | Function / Notes                                       |
|-------------|---------|--------------------------------------------------------|
| D0          | GPIO16  | Wake from deep sleep (ต้องต่อกับ RST), ไม่รองรับ PWM/I2C/interrupt |
| D1          | GPIO5   | I2C SCL (แนะนำ), PWM, Interrupt                        |
| D2          | GPIO4   | I2C SDA (แนะนำ), PWM, Interrupt                        |
| D3          | GPIO0   | Boot mode select — ต้อง HIGH เพื่อ normal boot; มี pull-up ภายใน |
| D4          | GPIO2   | Boot mode select — ต้อง HIGH เพื่อ normal boot; LED ที่ ESP-12E (active LOW); มี pull-up ภายใน |
| D5          | GPIO14  | SPI CLK (HSCLK), PWM, Interrupt                        |
| D6          | GPIO12  | SPI MISO (HMISO), PWM, Interrupt                       |
| D7          | GPIO13  | SPI MOSI (HMOSI), PWM, Interrupt                       |
| D8          | GPIO15  | SPI CS (HCS) — ต้อง LOW เพื่อ normal boot; มี pull-down ภายใน |
| RX          | GPIO3   | UART0 RX, ใช้เป็น GPIO ได้แต่มีผลต่อ Serial            |
| TX          | GPIO1   | UART0 TX, LED ที่บอร์ด NodeMCU (active LOW), มีผลต่อ Serial |
| A0          | ADC0    | Analog Input 0–3.3 V (ผ่าน divider ภายใน), ห้าม > 3.3 V |
| GND         | GND     | Ground                                                 |
| 3V3         | 3.3 V   | Power Output 3.3 V (จาก AMS1117-3.3 LDO)              |
| VIN / VU    | 5 V     | USB 5 V Output (สามารถใช้จ่ายไฟ peripheral ภายนอก)     |
| RST         | RESET   | Active LOW reset                                       |
| EN          | CH_PD   | Chip Enable — ต้อง HIGH เพื่อทำงานปกติ                 |
| SD3         | GPIO10  | ใช้งานได้บางส่วน (Flash SPI)                           |
| SD2         | GPIO9   | ใช้งานได้บางส่วน (Flash SPI)                           |
| CLK         | GPIO6   | Flash SPI — **ห้ามใช้**                                |
| SD0         | GPIO7   | Flash SPI — **ห้ามใช้**                                |
| SD1         | GPIO8   | Flash SPI — **ห้ามใช้**                                |
| CMD         | GPIO11  | Flash SPI — **ห้ามใช้**                                |

### Boot Mode Summary

| GPIO15 (D8) | GPIO0 (D3) | GPIO2 (D4) | Boot Mode           |
|-------------|------------|------------|---------------------|
| LOW         | HIGH       | HIGH       | Normal boot (Flash) |
| LOW         | LOW        | HIGH       | Flash programming   |
| HIGH        | X          | X          | SD-card boot        |

## Power Supply

| แหล่งจ่ายไฟ    | วิธี                          | ข้อควรระวัง                                    |
|----------------|-------------------------------|------------------------------------------------|
| USB Micro-B    | ต่อ USB จาก PC หรือ Adapter    | วิธีปกติ และใช้อัปโหลดโปรแกรม                  |
| VIN pin (5 V)  | ต่อแหล่งจ่าย 5 V ที่ pin VIN   | ผ่าน LDO บนบอร์ด ให้กระแสสูงสุด ~600 mA       |
| 3V3 pin        | ต่อแหล่งจ่าย 3.3 V            | **Bypass LDO** — ต้องเสถียรและจ่ายได้ > 500 mA |
| แบตเตอรี่ Li-Po | ผ่าน module charge + VIN      | ควรใช้ TP4056 + diode ป้องกัน                  |

> **สำคัญ:** ESP8266 ดึงกระแสสูงสุด ~300–400 mA ขณะ Wi-Fi transmit ควรใช้ decoupling capacitor 100 µF และ 100 nF ใกล้ pin 3V3

## Communication Interfaces

### UART (Serial)
```
UART0: TX = GPIO1 (D10/TX), RX = GPIO3 (D9/RX)  ← ใช้อัปโหลดและ Serial Monitor
UART1: TX = GPIO2 (D4) เท่านั้น  ← ใช้ debug log ได้
```

### I2C (Software)
```cpp
// ค่า default ใน Wire library
Wire.begin(SDA, SCL);  // SDA = GPIO4 (D2), SCL = GPIO5 (D1)
```
ต้องใช้ pull-up resistor 4.7 kΩ ที่ SDA และ SCL ไปยัง 3.3 V

### SPI (Hardware)
```
MOSI = GPIO13 (D7)
MISO = GPIO12 (D6)
SCLK = GPIO14 (D5)
CS   = GPIO15 (D8) หรือ GPIO ใดก็ได้
```

### ADC
```cpp
int value = analogRead(A0);  // คืนค่า 0–1023 (10-bit)
float voltage = value * (3.3 / 1023.0);
```

## PlatformIO Configuration

### platformio.ini (สำหรับ NodeMCU v2 / ESP-12E)
```ini
[env:nodemcuv2]
platform = espressif8266
board = nodemcuv2
framework = arduino
monitor_speed = 115200
upload_speed = 921600
; upload_port = COM5    ; ระบุ port ถ้ามีหลาย device

; Optional settings
board_build.f_cpu = 80000000L       ; 80 MHz (หรือ 160000000L)
board_build.f_flash = 40000000L     ; Flash frequency 40 MHz
board_build.flash_mode = dout       ; Flash mode (dout แนะนำสำหรับ 4MB)
build_flags =
    -std=gnu++17                    ; C++17 (toolchain xtensa-lx106 GCC 10.3)
```

### platformio.ini (สำหรับ NodeMCU v3 / LOLIN)
```ini
[env:nodemcu]
platform = espressif8266
board = nodemcu
framework = arduino
monitor_speed = 115200
```

## Code Examples

### Wi-Fi Connect
```cpp
#include <ESP8266WiFi.h>

const char* ssid     = "YOUR_SSID";
const char* password = "YOUR_PASSWORD";

void setup() {
    Serial.begin(115200);
    WiFi.begin(ssid, password);
    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
    }
    Serial.println("\nConnected! IP: " + WiFi.localIP().toString());
}

void loop() {}
```

### Deep Sleep
```cpp
// ต้องต่อ D0 (GPIO16) กับ RST
ESP.deepSleep(10e6);  // sleep 10 วินาที (หน่วยเป็น microseconds)
```

### OTA Update
```cpp
#include <ArduinoOTA.h>

void setup() {
    // ... WiFi.begin() ...
    ArduinoOTA.setHostname("my-esp8266");
    ArduinoOTA.begin();
}

void loop() {
    ArduinoOTA.handle();
}
```

## Common Pitfalls & Tips

1. **GPIO6–11 ห้ามใช้** — ต่ออยู่กับ Flash SPI chip ภายใน
2. **GPIO0, GPIO2, GPIO15** — มีผลต่อ boot mode อย่าดึง LOW ค้างตอนเปิดเครื่อง
3. **GPIO16 (D0)** — ไม่รองรับ interrupt, PWM, I2C; ใช้ wake จาก deep sleep เท่านั้น
4. **A0 voltage** — NodeMCU มี voltage divider (220 kΩ / 100 kΩ) รองรับ 0–3.3 V แต่ ESP8266 core รับได้แค่ 0–1 V
5. **3.3 V logic** — GPIO ทนแรงดันสูงสุด 3.6 V ห้ามต่อ signal 5 V โดยตรง ต้องใช้ logic level converter
6. **กระแสไฟ** — แต่ละ GPIO จ่ายได้สูงสุด 12 mA; รวมทุก GPIO ไม่เกิน 45 mA
7. **Serial บน boot** — ESP8266 print garbage data ที่ 74880 baud ตอน boot ก่อน sketch เริ่ม
8. **SPIFFS ถูกลบแล้ว** — ตั้งแต่ ESP8266 Arduino Core 3.x SPIFFS ไม่มีในแพ็กเกจอีกต่อไป ให้ใช้ LittleFS แทนทั้งหมด
9. **ArduinoJson v7** — API เปลี่ยนจาก v6 (ไม่มี `StaticJsonDocument`, ใช้ `JsonDocument` แทน)

## Comparison: ESP8266 vs ESP32 Family

| Feature         | ESP8266        | ESP32 (Classic)   | ESP32-S3          | ESP32-C3/C6       |
|-----------------|----------------|-------------------|-------------------|-------------------|
| CPU Cores       | 1              | 2 (Xtensa LX6)    | 2 (Xtensa LX7)    | 1 (RISC-V)        |
| CPU Speed       | 80/160 MHz     | 240 MHz           | 240 MHz           | 160 MHz           |
| RAM             | ~80 KB usable  | ~320 KB usable    | ~512 KB usable    | ~400 KB usable    |
| GPIO            | 11 usable      | 34 usable         | 45 usable         | 22 usable         |
| ADC Channels    | 1              | 18                | 20                | 6                 |
| Bluetooth       | ไม่มี          | BLE 4.2 + Classic | BLE 5.0           | BLE 5.0           |
| Wi-Fi 6 (802.11ax) | ไม่มี       | ไม่มี              | ไม่มี              | C6 เท่านั้น        |
| Thread / Zigbee | ไม่มี          | ไม่มี              | ไม่มี              | C6/H2 เท่านั้น    |
| DAC             | ไม่มี          | 2 channels        | 2 channels        | ไม่มี              |
| USB-OTG         | ไม่มี          | ไม่มี              | มี (native USB)   | ไม่มี              |
| Price           | ถูกที่สุด       | ปานกลาง            | ปานกลาง-สูง        | ปานกลาง            |
